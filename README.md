🌍 Travel Website
A responsive and modern travel-themed website built using HTML, CSS, and JavaScript. It features a clean layout with navigation, image gallery, destination cards, a contact form, and a modal login popup — perfect for showcasing beautiful travel destinations and engaging users.

📌 Features
✅ Responsive Navbar with dropdown and hamburger menu<br>

✅ Gallery Section showcasing random travel images <br>

✅ Contact Form with validation-ready inputs <br>

✅ Destination Cards highlighting top travel cities <br>

✅ Login Modal Popup with JavaScript interactivity <br>

✅ Mobile-Friendly Design using media queries <br>

✅ Smooth Hover Effects and transitions <br>

📁 Project Structure <br>

travel-website/<br>
