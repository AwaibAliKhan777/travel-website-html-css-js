🌍 Travel Website
A responsive and modern travel-themed website built using HTML, CSS, and JavaScript. It features a clean layout with navigation, image gallery, destination cards, a contact form, and a modal login popup — perfect for showcasing beautiful travel destinations and engaging users.

📌 Features
✅ Responsive Navbar with dropdown and hamburger menu

✅ Gallery Section showcasing random travel images

✅ Contact Form with validation-ready inputs

✅ Destination Cards highlighting top travel cities

✅ Login Modal Popup with JavaScript interactivity

✅ Mobile-Friendly Design using media queries

✅ Smooth Hover Effects and transitions
